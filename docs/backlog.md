# 나중에 할 일 (미뤄 둔 사소한 점)

3~5단계 독립 검토에서 나온 사소한 점 가운데 아직 고치지 않은 것을 우선순위로 모았다. 기준은 "사용자가 실제로 겪을 가능성과 불편의 크기"다. 고치면 이 목록에서 지우고 해당 단계 증거 문서에 적는다.

**10-08 Codex 감수:** 업로드 실패 표시(R2)·배경 탭 폴링(R3)은 아래 높음 항목으로 유지한다. 인계 현재 상태의 누락(R4)은 이번에 수정했다. 별도로 공개 전 수정 권장인 **중요 R1(`--no-upload`에도 진행 정보 전송)**은 [감수 증거](superpowers/evidence/2026-10-08-codex-review.md)에 조건·재현·수정 방향을 기록했다.

**10-08에 고친 것(1.0.2):** 감수 R1(업로드 생략 작업도 진행 정보 전송), R2(업로드만 실패해도 전체 실패로 표시 → 주황 카드 "PC에는 저장됐고 업로드만 실패" + 다시 올리는 방법, 닫을 때까지 유지), R3(숨겨진 목록 탭은 조회하지 않아 미니 서버가 1시간 뒤 꺼질 수 있음).

**10-08 Codex 재감수:** R1·업로드 재시도 상태·서버 검사 호환은 확인했다. 중요 N1(숨긴 동안 시작·완료된 강의의 목록 갱신 누락)은 우선 수정 권장. 사소 N2(닫지 않은 업로드 경고도 1시간 뒤 API에서 제외됨)·N3(Railway 최초 업로드 실패 카드에 없는 강의의 보기 링크 표시)는 표시 정책을 보완한다. 조건·실행 근거·수정 방향은 [재감수 기록](superpowers/evidence/2026-10-08-codex-rereview.md)에 있다. "닫을 때까지 유지"는 현재 1시간 이내에서만 성립한다. → **같은 날 Claude Code가 N1·N2·N3 모두 수정**(동작 테스트로 재현 후, 재감수 기록 끝 절).

**10-07에 고친 것:** 영상·작업 ID 끝 줄바꿈 허용(정규식 `fullmatch`), 화면을 다른 사이트 틀 안에 넣는 것 차단(CSP `frame-ancestors`), 6시간 넘게 멈춘 "진행 중" 카드 숨김(시간대 없는 시각도 오류 없이 건너뜀), 진행 상세 200자 제한, 깨진 `lecture.json` 업로드 안내, 업로드 401 때 `vl.py connect` 다시 실행 안내, 예시 주소 자리표시, README의 Mac 명령·`railway login`·`git clone`·업데이트·제거 안내, 설계서 3장 README 위치.

## 높음
- `vl.py connect`가 Git Bash(mintty)에서는 "자기 터미널에서 실행" 안내로 거부된다 → 안내 문구에 PowerShell·Mac 터미널 명시.
- 로그인 잠금은 서버 전체에 걸려, 누가 일부러 틀리면 관리자도 15분 잠긴다 → 안내서에 "Railway 재시작으로 풀림" 적기, 필요하면 방식 재검토.

## 보통
- 서버: 오류 응답(500) 때 보내던 본문을 받지 않아 Windows에서 이유 대신 연결 끊김으로 보일 수 있음 / 파일 교체·읽기 재시도 없음 / `/app/C:x` 같은 이름 허용 / HEAD·OPTIONS 501 / Host 확인 전에 사용 시각 갱신 / health에 버전 없음 / 서버 작업 폴더가 자료실이라 폴더가 잠김 / `server.log`가 계속 커짐.
- 진행 보고 3초 제한은 요청마다라, Railway가 느리면 한 강의에 최대 1분 남짓 늦어질 수 있음 → 첫 시간 초과 뒤에는 그 작업의 보고를 멈추기.
- 업로드 토큰이 있는 `config.json`이 OneDrive로 동기화될 수 있음(문서 폴더를 OneDrive로 옮긴 경우).
- 동시에 처리할 때 임시 파일 이름·`index.json` 갱신 잠금 없음.
- Codex 매니페스트에 표시 이름(`interface.displayName`) 없음 — 형식 확인 후 추가.

## 낮음
- 강의 화면: 유튜브 화면을 누른 뒤 단축키가 안 먹음 / 플레이어 준비 전 이동 무시 / 주소의 `t`가 영상 길이보다 커도 그대로 / 번역 언어가 둘 이상이면 첫 번째만 / 나란히 복사가 긴 강의에서 느림 / 자동 따라가기가 손 스크롤과 충돌 / 강조가 띄어쓰기에 민감.
- 접근성: 화면 읽기 프로그램 알림 과다·포커스 이동, 마우스 전용 조작, 탭 역할 표시.
- 0단계가 처리할 때마다 브라우저 탭을 새로 엶 / 이전 화면 파일이 `app/`에 남음.
- 교정 브리프에 "덧붙이기·지우기만으로 고칠 오류는 보고만" 명시, 맥락 브리프에 heard_as 표기 안내, 동시 처리 때 임시 파일은 작업 폴더 안에.
- 인계 문서에 남은 공개 정보 정리(다른 분 강의 번역 기록, 비밀번호 최소 길이), 다른 프로젝트 이름 언급 정리.
- Codex에서 `/plugin install`(대화창 안) 흐름과 PowerShell 규칙의 실제 동작 확인.
